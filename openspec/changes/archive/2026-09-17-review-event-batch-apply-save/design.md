## Context

`events.html` 逐行编辑、六项必填、`PUT /api/sla/review-events/{id}` 成功后 `writeAfterSave` 写 `sla_excluded_downtime`。未复盘行默认可编；已复盘行需点「编辑」。翻页会丢未保存改动。同类宕机无法一次套用再一次提交。

约束：Java 8、端口 8086、排除写口径不变、不在套用时写库、132 上排除写入仍走现有 INSERT/UPDATE（折叠重复窗口时的 DELETE 保持现状）。

## Goals / Non-Goals

**Goals:**

- 本页勾选；指定样板后把六项人填字段拷到勾选目标行。
- 对勾选且已填完的行逐条保存，复用单行校验与排除写入。
- Preview 页与正式页行为一致。

**Non-Goals:**

- Excel 导入、跨页勾选、跨页套用。
- 放宽必填或草稿保存。
- 套用时写 `sla_excluded_downtime`。
- 整批单一数据库事务回滚（双 JDBC 无法与主表对齐）。
- 按父/子窗口自动配对同步。

## Decisions

1. **样板来源**  
   行上提供「设为样板」。未指定时，套用使用本页自上而下第一条六项已齐的行。目标 = 当前勾选且 `id` 不是样板的行。覆盖目标的类别、子类、描述、三块长文，并按字典带出 `count_sla`。不链式「每行套上一行」，避免空行把空值传下去。

   仅 `templateRowId` 指向的显式样板高亮：主行、展开复盘行、该行内 select/textarea 铺满淡蓝 `#e8f4ff`，无品牌色左边条。样板优先于 dirty 黄底。「当前样板」用白底青绿描边（`.btn-tpl`），不得使用 `.btn-primary`。默认样板（第一条已填完、用户未点设为样板）不预亮。顶栏展示样板系统名。换样板时上一行高亮与按钮态一并去掉。

2. **套用只改本页内存**  
   标记 `_dirty`；若目标已锁定则打开 `_editing`。不请求 API。

3. **保存勾选走现有 PUT**  
   前端按当前页顺序对「勾选且 `isComplete`」的行串行调用与「保存本行」相同的请求。不完整勾选跳过。任一行失败则继续后续行，toast 汇总成功数、跳过数、失败 id/原因。不新增批量 REST，避免第二套排除写入。

4. **排除表**  
   每条成功 PUT 仍调用现有 `update` → `writeAfterSave`。键仍是目标库 `slaid` + `period_from(down_start)`；`period_to` 用**该行**保存后的 `exclude_time`（是/否按该行分类），不是样板行的结束时间。

5. **全选**  
   表头勾选仅本页 `rows`，与分页无关。

## Risks / Trade-offs

- [误套用覆盖已复盘长文] → 套用前若任一目标已有非空人填字段，确认后再覆盖。  
- [批量中途失败已写入排除库] → 逐条提交 + 失败列表；不假装整页回滚。  
- [样板未填完] → 套用拒绝并提示。  
- [全选后保存含未填行] → 跳过未填完，不报整批失败。

## Migration Plan

发版替换静态页即可。无需表结构变更。回滚用上一版 `events.html` / preview。
