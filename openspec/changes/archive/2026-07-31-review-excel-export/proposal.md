## Why

复盘目前依赖手工整理 Excel，易漏「未排除」宕机且口径不一。需要一键 API 导出标准双页签复盘表：低 SLI 待复盘与全量待复盘，便于责任人填写中断原因。

## What Changes

- 新增 API：调用后生成并下载一份 `.xlsx`。
- 文档含两个页签（「月份」仅用于命名，**不**按宕机开始时间过滤）：
  1. `{月份}-SLA小于99.9%待复盘`：子系统+父系统年度清单中 **年度 SLI &lt; 99.9%** 的系统 → 匹配子/父宕机明细 → 仅保留排除状态为「未排除」或「-」的宕机行。
  2. `{月份}-所有待复盘`：子系统+父系统年度清单**全量** → 同样匹配并过滤排除状态。
- 每行字段：系统名称、系统类别（父系统/子系统，按 SLI 源）、中断原因（空待填）、宕机开始时间、宕机结束时间、责任人（现有 `OwnerRuleResolver` 写具体姓名）。
- 一行对应一条宕机明细；企微推送与定时任务不变。

## Capabilities

### New Capabilities

- `sla-review-excel`: API 导出双页签 SLA 复盘 Excel（低 SLI / 全量 × 未排除宕机）。

### Modified Capabilities

- （无强制修改；实现时可扩展宕机查询读取「排除状态」，归入本能力实现细节。）

## Impact

- 新 API（建议 `GET /api/sla/review-excel`）、Excel 生成（需引入 POI 或 EasyExcel）
- 扩展：全量年度清单查询、宕机行「排除状态」字段
- 复用：双 SLI 源、子/父宕机看板、责任人规则
- 依赖：`pom.xml` 增加 Excel 库
